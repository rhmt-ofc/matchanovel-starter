Cara Build Game di Defold Engine

  1. 1
    Clone Repositori GitHub
    git clone https://github.com/rhmt-ofc/matchanovel-starter.git
  2. 2
    Buka Melalui Defold Editor

    Unduh editor resmi di defold.com, lalu pilih Open Project dan arahkan ke file game.project.

  3. 3
    Tulis Cerita & Dialog

    Cukup edit file teks assets/scripts/script.txt dengan sintaks label & narasi sederhana.

  4. 4
    Bundle Multi-Platform

    Pilih menu Project → Bundle untuk menghasilkan file HTML5 Web, Android APK, atau Windows EXE (<5 MB!).
